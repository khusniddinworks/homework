1-Qism: Writing Task 1 (Maps Grammar)

Xaritalarni tasvirlash qoidalari

Xaritalardagi o'zgarishlarni tasvirlashda odatda Present Perfect Passive (has been built, have been demolished) ishlatiladi, chunki biz qachon sodir bo'lganidan ko'ra, hozir qanday o'zgarish borligiga e'tibor beramiz.

  • Qurish/Qo'shish: construct, build, erect, introduce, add to.
  • Buzib tashlash/Olib tashlash: demolish, knock down, pull down, cut down, remove.
  • Kattalashtirish/Kengaytirish: expand, extend, enlarge, develop.
  • O'zgartirish: transform, turn into, convert, replace, modernize.

Grammar for Maps Ex. 1 (Fe'llarni to'g'ri qo'ying)

Javoblar:
1. has become
2. has been constructed
3. has been demolished
4. have taken place
5. has been knocked down / has been replaced
6. has been replaced
7. have been pulled down
8. have been built
9. has changed
10. has been turned into

Grammar for Maps Ex. 2 (Ot shaklini yasang)

Javoblar:
1. redevelopment
2. expansion
3. conversion
4. modernization
5. introduction
6. building
